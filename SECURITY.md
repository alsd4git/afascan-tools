# Sicurezza

## Segnalare una vulnerabilità

Usa [la segnalazione privata di GitHub](https://github.com/alsd4git/afascan-tools/security/advisories/new).
Non pubblicare dettagli di exploit o dati sensibili nelle issue o nelle pull request.

Indica il commit o la versione interessata, l'impatto previsto e i passaggi minimi
per riprodurre il problema. Usa solo esempi sintetici e materiale anonimizzato.
Non allegare referti, dati sanitari, screenshot personali o risultati OCR reali.
Se trovi una credenziale esposta, revocala o ruotala prima di condividere dettagli.

## Versioni e manutenzione

Verifica il problema sul branch predefinito `main` e, se usi una release,
sull'ultima pubblicata in questa repository. Le eventuali correzioni vengono
preparate sul branch predefinito; non sono previsti backport separati per versioni
precedenti. La gestione è best effort, senza tempi di risposta o risoluzione garantiti.
